# EInfosys Bank - Customer Registration Portal


## Project Title

**EInfosys Bank - Customer Registration Portal**



## Description

EInfosys Bank Customer Registration Portal is a beginner-to-intermediate level frontend web project developed using HTML5, CSS3, and Vanilla JavaScript.

The project represents a real-world banking customer registration system where users can create a new bank account by filling out a registration form.

The application includes client-side validation, responsive design, smooth scrolling, and dynamic success message generation after successful registration.

This project is created as a college assignment to understand frontend development concepts such as HTML structure, CSS styling, and JavaScript DOM manipulation.



## Features


### Navigation Bar

- Fixed navigation bar
- Circular "EI" logo
- EInfosys Bank branding
- Home, Services, and Contact navigation links



### Hero Section

- Welcome message
- Short banking description
- Open Account button
- Smooth scrolling to registration form



### Customer Registration Form

The form includes:

- Full Name
- Date of Birth
- Gender
- Mobile Number
- Email Address
- Address
- Account Type
- Initial Deposit
- Password
- Confirm Password
- Terms & Conditions checkbox



### JavaScript Validation

The project validates:

- Required fields
- Name containing only letters and spaces
- Valid 10-digit mobile number
- Valid email format
- Minimum initial deposit of ₹1000
- Password length of minimum 8 characters
- Password matching confirmation
- Terms & Conditions acceptance



### Successful Registration

After successful form submission:

- Default form submission is prevented
- Customer details are displayed dynamically
- Success card appears
- Form gets reset automatically



### Responsive Design

The website works on:

- Desktop screens
- Tablets
- Mobile devices

1. Download or clone the project folder.

2. Open the project folder.

3. Open `index.html` in any web browser.

4. The website will run directly.

No installation or external libraries are required.
